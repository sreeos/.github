# SreeOS

**An offline, local-first OS that runs in the browser.** Your files, apps and settings live on your device.

## Repositories

| Repo | What it is |
|---|---|
| [sreeos](https://github.com/sreeos/sreeos) | The OS itself |
| [apps](https://github.com/sreeos/apps) | The official App Store catalog, live at [sreeos.github.io/apps](https://sreeos.github.io/apps/) |

## Build an app

Make an app in SreeOS's **App Studio**, then add it to the store with a pull request to
[apps](https://github.com/sreeos/apps). See [CONTRIBUTING.md](https://github.com/sreeos/apps/blob/main/CONTRIBUTING.md).
